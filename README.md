# Easy Compare

**轻量化文件备份同步工具** — 基于 Tauri 2 + Rust 的 Windows 桌面应用：比对任意两个目录的文件差异，以单向增量方式安全备份到目标目录（例如笔记本 → 移动硬盘），之后可随时重新比对并更新备份。

界面为单窗口双栏：左栏源文件夹，右栏目标文件夹，中间是「状态」与「复制」两窄列；目录折叠在左右两栏始终同步。

---

## 功能

- **六态差异判定**：冲突 / 仅源有 / 仅目标有 / 内容不同 / 已同步 / 未比对；每行同时用色条、文字标签、中间列符号三重编码，并按状态整行填色。
- **两种比对依据**：大小 + 修改时间（默认，容差 2 秒）、SHA-256 精确校验；也可只对选中项单独做哈希校验。
- **目录折叠**：逐级折叠展开，左右两栏同步；工具条提供「展开全部 / 收起全部」。
- **单行选中**：文件行选自身，目录行选整棵子树（折叠状态下同样生效）；状态列右侧「复制」列可一键把该行置为当前选择并打开预演清单。
- **虚拟滚动**：只渲染一屏多一点的 DOM，16800 个文件时约 24 行。
- **筛选与搜索**：只看差异、按状态筛选、文件名搜索；过滤规则支持扩展名、通配符、目录名，随会话持久化。
- **预演 → 确认 → 执行**：预演不产生任何写入，确认后逐项执行并回传进度，单项失败不中断整批。
- **其他**：结果报告导出（JSON）、会话持久化、盘符变化后按卷标识重新绑定、深浅色主题、自绘标题栏。

## 六态状态机

判定顺序固定，先命中者生效。

| 序 | 状态 | 编码 | 默认动作 |
|---|---|---|---|
| 1 | 冲突 | 紫 / `!` | 阻断自动执行，须逐项选择「用源覆盖 / 保留目标 / 跳过」 |
| 2 | 仅源有 | 琥珀 / `→` | 新增复制到目标 |
| 3 | 仅目标有 | 灰 / `←` | 默认保留，仅镜像模式才移走 |
| 4 | 内容不同 | 红 / `≠` | 源覆盖目标（目标较新时额外标 `←` 警示） |
| 5 | 已同步 | 绿 / `=` | 不参与操作 |
| 6 | 未比对 | 浅灰 / `·` | 不参与批量操作 |

目录节点不参与写入判定，只汇总子树差异计数，中间列固定显示 `·`。界面底部图例默认收起，只留一个 `i` 图标，点击展开。

## 安全约束

1. **默认不删除**。`mirrorMode` 默认关闭；开启需在预演对话框勾选并二次确认，确认框逐条列出待移除文件。待删项移入目标盘 `.easy-compare/versions/<时间戳>/deleted/`，不直接抹除。
2. **覆盖前留旧版**。`keepOldVersions` 默认开启，旧文件按相对路径移入 `.easy-compare/versions/<时间戳>/replaced/`。写入采用「同目录临时文件 → 设置修改时间 → 原子替换」。
3. **路径与卷校验**。前端只传会话标识、相对路径与开关，绝对路径到磁盘的映射全部在 Rust 侧完成；`safe_rel` 拒绝 `..`、绝对路径与盘符。会话记录目标卷序列号 + 卷标，**预演时、执行前、每写一项前**都重新校验，不匹配即拒绝写入。
4. **不完整比对禁止执行**。扫描被取消或中断时结果带 `aborted` 标记，不会生成可执行计划。

## 快速开始

### 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11（需 WebView2 运行时） |
| Rust | 1.89+（`tauri` 固定为 `=2.11.5`，见 `src-tauri/.cargo/config.toml`） |
| Node.js | 18+ |
| 构建工具 | MSVC Build Tools |

> `tauri` 2.12.x 的 MSRV 为 Rust 1.90，因此本项目把 `tauri` 固定为 `=2.11.5`、`tauri-build` 为 `=2.6.3`、CLI 为 `2.11.5`。升级到 Rust 1.90+ 后可解除固定。
>
> 目录选择未使用官方 dialog 插件（其当前版本要求 Rust ≥ 1.90），改由 Rust 侧直接调用 Win32 API 枚举盘符与浏览目录，零额外依赖，并能展示卷标与可移动磁盘类型。

### 运行与构建

```bash
npm install      # 安装 @tauri-apps/cli
npm run dev      # 开发模式
npm run build    # 生成安装包到 src-tauri/target/release/bundle/
```

产物：

| 产物 | 路径 |
|---|---|
| NSIS 安装版（推荐） | `src-tauri/target/release/bundle/nsis/Easy Compare_0.0.1_x64-setup.exe` |
| MSI 安装版 | `src-tauri/target/release/bundle/msi/Easy Compare_0.0.1_x64_en-US.msi` |
| 免安装主程序 | `src-tauri/target/release/easy-compare.exe` |

### 只看界面

不需要 Rust 环境：用浏览器直接打开 `src/index.html`，会自动进入「演示数据」模式，全部界面交互可独立验收。

### 测试

```bash
cd src-tauri && cargo test   # 单元测试 + 真实磁盘端到端冒烟测试
npm run verify               # 前端交互验证（headless Chromium，截图输出到 .verify/）
```

## IPC 命令

| 命令 | 作用 |
|---|---|
| `validate_and_bind` | 校验可访问性、可写性、卷标识，创建或更新会话 |
| `rebind_target` | 盘符变化后按卷标识识别同一卷；不匹配须显式强制重绑 |
| `compare` | 后台递归扫描，增量回传 `scan-progress`，六态比对，支持取消 |
| `cancel_scan` | 置取消标志 |
| `verify_hashes` | 仅对选中项计算 SHA-256，不触发全量重算 |
| `create_plan` | 生成预演计划，复算容量与空间；计划留在 Rust 侧，只回传 id |
| `execute_backup` | 一次性令牌执行，逐项进度事件 |
| `refresh_after_backup` | 执行后重新比对、刷新状态树 |
| `list_drives` / `browse_dirs` | 目录选择 |
| `list_sessions` / `active_session` / `delete_session` | 会话持久化（应用数据目录 `sessions.json`） |
| `export_report` | 导出结果报告 JSON |
| `app_info` | 产品与路径信息 |

## 数据目录

比对与备份在目标盘维护一个内部目录，默认不参与比对：

```
<目标目录>/.easy-compare/
├── baseline.json                源端基线（含卷标识）
└── versions/<时间戳>/
    ├── replaced/                被覆盖的旧文件
    └── deleted/                 镜像模式下移除的文件
```

基线优先写目标盘；目标盘不可写时降级到应用数据目录并在界面提示。基线中的卷标识与当前会话不一致时会被忽略并提示。

## 已知限制

- **时间戳精度**：NTFS 与 exFAT 的修改时间粒度和时区语义可能不同，`MTIME_TOLERANCE_SECS = 2` 仅作默认容差，未做量化验证。疑似误判时请切换到 SHA-256 精确校验。
- **卷标识稳定性**：卷序列号在同一分区格式化前后会变化，部分 USB 桥接芯片上报方式也可能不同；盘符变化后只在卷标识一致时自动重绑。
- **超长路径**：`canonicalize` 返回的 `\\?\` 前缀在存储与展示前会被剥掉，标准库读写 API 会自动按需加回；符号链接与目录联接一律跳过并计数。
- **规模**：后端一次性把完整树序列化返回，几十万文件量级需改为分页或流式返回（未实现）。
- **平台**：首版仅针对 Windows，非 Windows 分支只有可编译的降级实现。
